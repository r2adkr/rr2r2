프로젝트 목적 & 개요

학교의 비전과 주요 정보를 사용자가 쉽게 파악할 수 있도록 구성한 종합 웹 사이트 프로젝트입니다. 전공 학과 안내부터 주요 교육 사업, 데이터 기반 인포그래픽, 미디어 영상까지 한눈에 살펴볼 수 있도록 직관적인 UI로 설계했습니다.

주요 구성 콘텐츠

  • 학교 소개: 학교의 개요, 교육 목표 및 안내 정보 수록
  • 전공 학과 안내: 학과별 특성 및 주요 커리큘럼 소개
  • 주요 교육 사업: 학교에서 운영 중인 특성화 사업 및 맞춤형 교육 프로그램
  • 인포그래픽 & 분석: 핵심 수치 및 시각화 데이터 그래픽 수록
  • 소개 동영상: 생생한 현장을 담은 학교 홍보 동영상 미디어 임베드

InsanityMod 상세 정보

Lethal Company V80-81 모드 프로젝트

광기(Sanity) 실시간 수치 메커니즘

시설 내부 입장 시 광기 수치가 점진적으로 증가(혼자 있을 시 약 10분 만에 100% 도달)하며, 야간/Eclipse/수중 환경 및 적 근처 시 가속화됩니다. 동료와 근접해 있거나 전등을 켜두면 회복됩니다.

단계별 시각 및 오디오 환각 연출

  • 70%: Dissonance VOIP 버퍼를 활용한 3D 위치 왜곡 음성 재생
  • 80%: 붉은 펄스 터널 비전(Vignette) 및 Ghost Girl 타겟 속도 증가
  • 90%: Perlin-noise 기반 카메라 흔들림 현상
  • 100%: 이동 정지 후 암전되며 Masked 몬스터로 변신 사망

Paranoia 커스텀 날씨 시스템

WeatherRegistry 연동으로 제작된 3% 확률의 Paranoia 날씨 이벤트는 시설 내부 광기 누적 속도를 상승시키고 적들의 활동성을 극대화합니다.

powder-orm 상세 정보

OSS-Ncode 대회 출품 오픈소스 프로젝트

프로젝트 핵심 개요

데이터베이스 관계형 매핑 시 타입 추론 및 컴파일 타임 구문 검사를 강화하여, 개발 과정에서의 실수나 런타임 SQL 에러를 획기적으로 낮추기 위해 시작된 TypeScript ORM 라이브러리입니다.

주요 기능 및 특징

  • Type-safe Schema definition 체계 제공
  • 직관적이고 유연한 SQL 쿼리 빌딩 API 지원
  • IDE 자동 완성 연동으로 개발자 생산성 증대

공식 문서 및 오픈소스 협업

사용자가 쉽게 모듈을 도입할 수 있도록 docs.powder-orm.info 웹 문서를 직접 구축·배포하였으며, GitHub 커뮤니티 가이드라인을 작성하여 오픈소스 기여 방식을 정립했습니다.
