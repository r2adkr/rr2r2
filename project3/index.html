비디오 파일: 1.mp4
Scene Frame 01 설레는 등교 (1)

새로운 시작, 활기찬 등교길

🎬 비디오 실제 내용

아침 햇살이 부드럽게 쏟아지는 학교 교문 안으로 민우와 서현이 가방을 메고 서로 웃으며 대화하며 걸어 들어옵니다. 주변에는 다른 학생들도 활기찬 발걸음으로 등교하고 있습니다. 두 학생은 카메라를 바라보며 미소를 지으며 걸어갑니다.

🎥 카메라 앵글

앞으로 걸어오는 인물들을 따라 카메라가 부드럽게 뒤로 후퇴하며 촬영하는 로우 앵글 트래킹 샷.

💡 조명 및 분위기

밝고 따뜻한 아침 자연광, 역광이 살짝 비치는 싱그러운 분위기.

💬 나레이션 자막

"새로운 기술과 꿈이 시작되는 곳, 오늘 하루도 활기차게 시작합니다."

비디오 파일: 2.mp4
Scene Frame 02 IoT 스마트 제어 실습 (2)

정교한 브레드보드와 아두이노 제어

🎬 비디오 실제 내용

IoT 실습실 책상 위에서 서현이 정교한 손놀림으로 브레드보드에 빨간색 점퍼 와이어를 꽂아 아두이노 보드와 연결합니다. 와이어가 연결되는 순간, 보드 위의 소형 LED 전구에 초록색 불빛이 깜빡이기 시작하고 옆의 태블릿 PC를 조심스럽게 조작합니다.

🎥 카메라 앵글

손끝과 태블릿 디스플레이에 초점을 맞춘 익스트림 클로즈업(Extreme Close-up)에서 포커스 아웃되는 앵글.

💡 조명 및 분위기

실험실 내부의 차가운 톤의 백색 LED 조명과 태블릿에서 뿜어져 나오는 은은한 광원.

💬 나레이션 자막

"직접 설계하고 연결하며, 사물인터넷 세상의 원리를 몸소 깨우칩니다."

비디오 파일: 3.mp4
Scene Frame 03 VR 콘텐츠 체험 실습 (3)

가상과 현실을 잇는 첨단 VR 스튜디오

🎬 비디오 실제 내용

넓고 가구가 정돈된 실제 VR 실습 공간의 중심에 선 민우가 VR 헤드셋을 착용한 채 양손에 컨트롤러를 쥐고 허공을 향해 팔을 뻗어 조작하는 동작을 취합니다. 옆에는 단정한 교복 차림의 멘토 선배가 서서 미소를 지으며 민우의 실습을 격려합니다.

🎥 카메라 앵글

두 인물을 중심으로 카메라가 반원 형태로 부드럽게 회전하며 첨단 장비를 부각하는 시네마틱 돌리 샷.

💡 조명 및 분위기

차분하게 정돈된 실내 공간 속에 블루와 퍼플 톤의 화려한 네온 앰비언트 LED 조명이 주는 조화.

💬 나레이션 자막

"가상과 현실의 경계를 허무는 VR 실습을 통해 미래형 공간 디자인을 설계합니다."

비디오 파일: 4.mp4
Scene Frame 04 VS Code 프로그램 코딩 (4)

다크 테마 에디터와 협업 코딩

🎬 비디오 실제 내용

컴퓨터 화면 가득 다크 테마의 VS Code 에디터 프로그램이 켜져 있고, 알록달록 구문 강조된 소스 코드들이 띄워져 있습니다. 민우가 화면의 특정 코드 줄을 친근하게 가리키며 설명하고, 옆에 앉은 지혜는 밝은 미소를 지으며 함께 화면을 보며 마우스와 키보드를 만집니다.

🎥 카메라 앵글

모니터의 VS Code 코드 화면을 좌측에 배치하고 열정을 담아 코딩을 토론하는 학생들의 모습을 가로로 담아내는 오버 더 숄더 뷰.

💡 조명 및 분위기

코딩 모니터 화면의 오색 스크린 빛이 아늑하게 밝혀주는 실내 조명 효과.

💬 나레이션 자막

"스스로 생각하고 코드로 구현하는 과정 속에서 문제 해결력을 키워나갑니다."

비디오 파일: 5.mp4 (6번)
Scene Frame 05 노을길 하교 (6번)

황금빛 노을 아래 단짝 친구들의 하교길

🎬 비디오 실제 내용

모든 일과를 마친 방과 후, 학교 정원의 나무들 사이로 붉고 따스한 노을빛이 가득 물들어 있습니다. 민우와 지혜, 동현, 수민 네 명의 단짝 친구들이 가방을 어깨에 메고 정원 산책로를 따라 다정하게 대화를 나누며 행복하게 하교합니다.

🎥 카메라 앵글

걸어가는 친구들의 자연스러운 뒷모습과 옆모습을 따라 부드럽게 뒤로 빠지는 시네마틱 트래킹 샷.

💡 조명 및 분위기

화면 전체를 따뜻하고 평화롭게 감싸 안는 주황빛 노을의 감성적인 골든 아워(Golden Hour) 역광.

💬 나레이션 자막

"실무로 다져진 탄탄한 실력, 내일의 첨단 기술을 선도할 우리의 미래가 이곳에서 완성됩니다."
